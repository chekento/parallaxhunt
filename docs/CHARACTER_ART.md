# Character art — 1.22.0

The project asset is `assets/visual/materials/characters_ink.png`. It was generated with the built-in Imagegen tool and copied into the game. The original alpha channel is preserved. The atlas has four columns and four rows; each row is one outfit, ordered south, west, north and east. No external image service is needed while playing.

The game anchors each cell at its feet and adds walking bob and sway procedurally. These are four directional standing drawings, not a full frame-by-frame walk animation. The next art pass should add actual stride frames and additional district outfits.
